# Security policy

Security issues & concerns are addressed by the product maintainer, [@teh-hippo](https://github.com/teh-hippo).

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/teh-hippo/ha-govee-led-ble/security/advisories/new) for suspected vulnerabilities.

Include the affected component, workflow, dependency or immutable release reference, impact and reproducible steps.
Remove credentials, tokens, personal information and unrelated private data.
