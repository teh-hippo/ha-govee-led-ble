# H6199 Pact 1 Restriction

A positively observed advertisement identifying H6199 Pact **1/1** selects a
partial, power-only device profile. Power control/readback and main firmware
and hardware identity queries remain available. Brightness, colour, segments,
music, scenes, video and effect uploads are not qualified through the newer
H6199 grammar and are disabled, including saved profiles and queued writes.
Unsupported notifications cannot install state or supply recovery evidence.
The light exposes on/off only and is excluded from Effect Studio's device list.

HW `1.00.01` does **not** identify Pact. Unknown Pact retains shipped model
behaviour for compatibility; that behaviour is unqualified, not proof of Pact 2
wire compatibility. An absent/malformed advertisement does not erase a known
Pact restriction. A later explicit Pact 2/1 advertisement restores the normal
model profile, subject to its existing firmware/identity gates. Profile changes
discard incompatible retained control state rather than promoting it to fresh
observations.

This is not implementation or qualification of Pact 1 brightness or effects.
The generated command/query semantic guard permits only the restricted
profile's operations at the physical write boundary. No hardware-version
heuristic, raw opcode filter, firmware change or effect upload is introduced.
