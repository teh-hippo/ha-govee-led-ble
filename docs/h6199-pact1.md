# H6199 Pact 1 Restriction

A positively observed advertisement identifying H6199 Pact **1/1** selects a
partial profile. Power control/readback, whole-strip RGB, brightness writes,
and main firmware and hardware identity queries remain available. The RGB
writer follows the owner's official-app capture: mode selector `0x0b`, RGB,
and whole-strip mask `0x7fff`. Brightness writes map percentages to the
legacy raw range `1..253`; the `0xfe` value in the capture is treated as a
query sentinel. The profile does not claim colour or brightness
readback; it remains optimistic across those writes. Segments, colour
temperature, music, scenes, video and effect uploads remain disabled.
Unsupported notifications cannot install state or supply recovery evidence.
The light remains excluded from Effect Studio's device list.

HW `1.00.01` does **not** identify Pact. Unknown Pact retains shipped model
behaviour for compatibility; that behaviour is unqualified, not proof of Pact 2
wire compatibility. An absent/malformed advertisement does not erase a known
Pact restriction. A later explicit Pact 2/1 advertisement restores the normal
model profile, subject to its existing firmware/identity gates. Profile changes
discard incompatible retained control state rather than promoting it to fresh
observations.

The Pact 1 RGB and brightness writes are qualified only by the attached
H6199 Pact 1/1 app capture; broader hardware revisions and status readback
remain unqualified. The semantic guard permits only power, brightness and
whole-strip RGB at the physical write boundary. No hardware-version heuristic,
firmware change or effect upload is introduced.
